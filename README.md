## Como trabalho

- Começo pelo problema e deixo as decisões técnicas visíveis.
- Separo regras de negócio da interface e cubro os casos críticos com testes.
- Trato privacidade, segurança e acessibilidade como requisitos de produto.
- Documento limitações com clareza, sem prometer precisão que o software não possui.
